## Overall impression (a few sentences)

- Scientific correctness: No issue, all good
- Speed and smoothness: Look good
- Layout and look: Not bad, but when the data view window gets split hortizontally into two, the original embedding view becomes narrow. The layout also becomes confusing if multiple datasets are opened and some of them with the plot view opened, as all views, regardless embedding or plot views, get equally tiled into grids. I'm wondering, whether the layout would be improved, if the plot view is always to split the window of the embedding view of the same dataset vertically. For example, the embedding view takes the 2/3 on top, and the 1/3 at the button turn into the plot view. If there are multiple dataset opened, the plot view window is always generated by splitting the embedding view window of the dataset rather than simply adding another tile to the grid.
- Wording: Look good
- Expected but missing: Nothing obvious at the moment
